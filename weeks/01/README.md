# Week 1: Your first coding-agent session

**Monday, September 14, 2026 · 1:30–4:10 PM · MC-225**

Bring your laptop and charger. We will install and configure the tools together; no advance setup is assumed. You have used Python and Java before. You do not need prior web development experience or a strong OOP background for today's work.

By the end of the session, you should be able to:

- Explain the difference between a model, a coding-agent harness, and the application it builds.
- Launch Claude Code with the OpenRouter model selected in class.
- Ask the agent to build a small application, then make one deliberate change.
- Check behavior yourself and explain what your checks establish.
- Save your work in Git and identify where to check model usage and spending.
